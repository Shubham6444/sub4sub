Privacy Policy

Last updated: October 13, 2026

This page describes how this private VibeTube Studio project handles information when you sign in and use its creator tools. The project is operated by the person who runs this instance; it is not operated by Google or YouTube.

Information this app handles

  • Google and YouTube authorization: When you sign in, Google returns access and refresh tokens. The app places them in an encrypted, HttpOnly session cookie so it can make the YouTube API requests you authorize. The app does not request your Google email address.
  • Channel and video data: The app retrieves channel details, video metadata, statistics, subscriptions, ratings, and comments from YouTube when you use the related features. It sends actions you choose—such as editing or uploading a video, commenting, liking, or subscribing—to YouTube.
  • Creator directory: The local db.json file stores listed YouTube channel IDs, the featured/member listing type, optional handle, and the time a member channel was added.
  • API usage record: The app updates one record in db.json with the total YouTube API request count and the latest request time, method, and endpoint path. API keys and query values are not included in that endpoint path.
  • Uploads: A video or image you choose is sent through the app server to YouTube for the requested operation. This project does not intentionally save upload files to its local disk.

How information is used and shared

The app uses authorization and channel data to show your creator dashboard and to carry out actions you request. Requests and upload content go to Google/YouTube. The browser may also connect to YouTube when you open a channel or use the embedded player. Google and YouTube process information under their own terms and privacy practices: Google Privacy Policy and YouTube Terms.

This project does not include an advertising or analytics integration. The computer or hosting provider running this instance may keep its own network or server logs.

Cookies and security

The app uses an OAuth state cookie during sign-in and a session cookie after sign-in. The session cookie is HttpOnly, uses SameSite=Lax, expires after 30 days, and is marked Secure when the app runs in production mode. The token data in the cookie is encrypted by the server using SESSION_SECRET. Local development has a built-in fallback; deployed instances must use a unique secret, keep it private, and use HTTPS.

Retention and deletion

The session cookie remains until it expires or you sign out. Signing out clears the app's session cookie but does not remove a channel from the local directory. Directory entries and the rolling API usage record remain in db.json until the instance operator changes or deletes them. To remove a directory entry, contact the person who operates this private instance. You can also revoke this app's Google access from your Google Account security settings.

YouTube data displayed by the app is retrieved from YouTube; it is not a separate permanent copy stored by this project unless described above.

Children and changes

This private project is not designed for children under 13. The operator may update this notice if the app's data practices change. The current version is available at /policy.

Questions

For privacy or deletion requests, contact the administrator who gave you access to this private instance. No separate support email or business identity is configured in this project.

Before making this app available to other people, the operator should add their real contact details and review this notice against the deployed configuration and applicable laws.
